# Effectiveness corpus

The JSON cases are evaluation data, including intentionally defective source strings.
Do not repair the defect variants. Expected bugs, fixture-specific deterministic
signals and hidden oracles are scoring metadata, never model input. Runners create
disposable repositories, execute trusted configured tools and retain raw evidence
outside version control. See [P21](../../docs/P21_EFFECTIVENESS.md) for measured
results, limits, reproduction and fresh AI labeling requirements.
